# Simulador de Transmisión Mecánica

Prototipo funcional desarrollado como parte del proyecto académico
de Ingeniería de Requisitos.

## Descripción

El proyecto consiste en un prototipo interactivo para la simulación
y demostración de las principales operaciones de una transmisión
mecánica.

El prototipo permite demostrar los requisitos funcionales RF-01 a
RF-07 definidos en el documento de especificación de requisitos.

## Requisitos funcionales

- RF-01: Cambio de marcha
- RF-02: Subir marcha
- RF-03: Bajar marcha
- RF-04: Cambiar modo de funcionamiento
- RF-05: Gestionar el embrague
- RF-06: Gestionar la caja de cambios
- RF-07: Gestionar los engranajes

## Prototipo

El prototipo cuenta con una interfaz interactiva y responsive que
permite visualizar y manipular los diferentes estados de la
transmisión.

## Tecnologías

- React
- CSS
- JavaScript

## Propósito académico

Este repositorio forma parte del proceso de Ingeniería de Requisitos
y se utiliza para apoyar la validación de los requisitos funcionales
mediante un prototipo interactivo.
